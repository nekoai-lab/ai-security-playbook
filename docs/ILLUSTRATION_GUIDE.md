# 黒猫と図解の使い方

素材一覧：[承認済みイラスト素材集](../design/assets/illustration-library/README.md) / 機械向け：[catalog.json](../design/assets/illustration-library/catalog.json)

## 最初に読むところ

- 正式ロゴは羅針盤と猫のA。黒猫の表情やポーズへ差し替えない。
- 既存の後ろ姿Cは入口や案内の部品として維持する。
- 記事用の黒猫はAPIキーの挿絵と修正版表情6種が顔立ちの基準。黒い毛、やや細めの輪郭、自然な目と鼻先、細いインクの毛並み、オレンジのリュックを保つ。
- 目や頬を膨らませ、子猫の丸顔や大きな涙で別キャラにしない。旧喜怒哀楽4種は使わない。表情は目線・耳・口元の小さな変化で付ける。

## 何に使うか

| 素材 | 向く場所 | 注意 |
| --- | --- | --- |
| 設定する・調べる場面の挿絵 | 導入、記事カード、話題の転換 | 架空の場面。技術や安全性の証拠にしない |
| ポーズ9種 | 案内、目線の誘導、図の横 | ポーズの参考。顔立ちは正本へ寄せる |
| のぞく・尻尾・後ろ姿 | 特集カード、余白の遊び | 文字、クリック領域、フォーカスを隠さない |
| 肉球・足跡 | 小さな見出し飾り、節の区切り | 完了印や安全認証として使わない |
| 修正版表情A/F | 通常の案内、好奇心 | 基本の顔立ちを揃える |
| 修正版表情E | 理解の区切り、穏やかな喜び | 実作業の成功・対応完了を推測しない |
| 修正版表情C/D | つまずきの場面、読者への共感 | 読者を責めたり、不安をあおったりしない |

図解は、情報の流れ・権限の境界・コードと結果を実テキストで示す。猫は読む楽しさと案内を担当する。図の説明を猫だけに任せない。

## 生成・素材化するとき

1. catalog.jsonから用途に合う原本を選ぶ。構図の参考と顔立ちの参照を混同しない。
2. 新しい顔やポーズは、APIキーの挿絵と修正版表情を参照画像に指定する。ポーズだけを変え、目・輪郭・毛並み・リュックを保つよう明示する。
3. 見本シートには番号、文字、カード枠がある。実際に使うときは必要なポーズを個別の素材として用意し、番号や枠を含めない。生成画像を使う場合は元の顔立ちと手足・尻尾も目視する。
4. 原本PNGと生成指示を保存し、Web用には必要な寸法のWebP等を用意する。透過が必要なら本当のアルファチャンネルを確認する。
5. イラスト中に読ませる文章やコードを描き込まない。見出し・説明・キャプションはHTMLで置く。

再生成用の共通指定：

> 元のAPIキー挿絵と修正版表情を同じ個体の参照にする。黒い猫、やや細めの顔、自然な目と鼻先、三角の耳、細い彫刻調インクの毛並み。オレンジの探検用リュックと巻いたマットを保つ。変えるのは指定した向き・ポーズ・控えめな表情だけ。丸顔、巨大な白目、膨らんだ頬、別の毛柄、3D調へ変えない。背景・透過・余白は用途に合わせ、文字・コード・ロゴ・安全の保証印を画像へ入れない。

## ウェブサイトに置くとき

- 既存のReadingArt / ReadingCard / ArticleVisual / ExplorerCatを使えるか先に確認する。
- 頭がカードの上に出る場合は余白を予約する。尻尾もページ外へはみ出させない。文字200%でも重ならないようにする。
- 装飾だけなら空のalt、操作を持たない飾りはクリックを受けない配置にする。意味を担う画像は周囲の説明と代替説明を揃える。
- すべてのカードへ同じ猫を反復せず、場面とリズムに合わせて使う。赤・緑や猫の表情だけでリスクを判定させない。
- 画像寸法・遅延読み込み・srcset/sizesを確認する。原本や見本シートをそのまま大きく配信しない。
- UIに組み込む変更では通常のcheck/build/testとFULL検査、320/375/768/1280px、キーボード・文字200%・目視を行う。素材の保存だけを、サイトへの配置完了と扱わない。


## 記事で使う部品

`CatGuide` は `pose="investigate"`（調べる猫、標準）または `pose="peek"`（上からのぞく猫）と `title`、本文を受け取る。`PawDivider` は肉球の装飾区切り。最初の採用例は `src/content/lessons/commands.mdx`。見出しや注意の意味はHTMLの実テキストが担う。

同じ記事で繰り返しすぎず、導入・誤解しやすい区別・節の転換へ配置する。のぞく猫のための上余白はCSSで予約済み。装飾画像は操作を受けず、空のaltで読み上げを増やさない。正式なコンパスロゴとは用途を分ける。320/375pxの文字200%でも本文との重なりがないことを採用ごとに確認する。
