# AI Security Playbook 設計

ユーザー指定の Astro + MDX / GitHub Pages / 日本語教材を実装する。
トップは学習ルート・教材一覧・今後のテーマ。本文は目次、一次資料、更新日、図解、確認手順を持つ。
コンテンツコレクションで category / title / summary / updated / order を検証する。
白と深緑の落ち着いた編集デザイン。スマートフォンでは一列。外部フォントや解析タグは使用しない。
資料はユーザー指定のMac mini Desktopから確認済み。公開記事とNode公式発表を照合する。実装・検証・公開操作はMac miniで実施。
実例を一般化せず、製品個別の影響・修正状況は未確認と明記する。確認コマンドは読み取り専用とする。
