# 個人開発・AI教材の拡充設計

承認日2026-10-24。AI利用者と、AIで作る非エンジニアを主対象に、8分野へ整理する。
分野はAIを使う前、アプリの仕組み、秘密とデータ、ログインと権限、MCP/エージェント、公開前、公開後、困ったとき。
新9教材は情報入力、アプリ構成、APIキー、認可、MCP、エージェント、公開前チェック、PHP更新、異常時対応。
全9教材へ対象と前提、仕組みの図、想定リスク、過去の事例の事実と限界、役割別表、具体的な確認と判断、証拠付きチェックリスト、次の行動、一次資料と確認日を置く。事故・脆弱性・再現実験・架空例を区別。一次情報がない事故を創作しない。
確認日2026-10-24。PHPの21日と23日の案内を分離し、提供元の修正を番号だけで断定しない。MCPは2026-07-28の資料を使用。指示や表示を実際の権限制御と同じ扱いにしない。
CONTENT_STANDARDをAGENTS/AI_GUIDE/AUTHORINGへ接続し、新教材の構成漏れを検出する。旧5教材は移行前として別表示し、適合済みの件数へ含めない。
依存追加なし。既存URL、FIELD NOTES、猫A/C、README/LICENSE、最小文字と操作領域を維持。秘密の貼付、攻撃実行、強制停止・削除、入力保存/ダウンロードは追加しない。
全生成画面の4幅、型・ビルド・リンク・内容構成と参照、検索と回遊、文字200%、キーボード、目視を検証し、CI成功後に公開URLを確認する。
