# 育つ教材ライブラリ / 承認済み設計

ユーザーが2026-10-24にテーマ別図書館と目的別学習ルートの併用を承認し、実装を指示。
トップは入口に限定し、テーマ・ルート・注目1件・新着少数を表示。全教材は専用一覧へ。
分類はテーマ、前提知識、形式を分離する。公開教材があるテーマだけ公開する。Node.jsは開発・実行環境の実践シリーズとし、運用教材は更新・運用にも所属する。
教材一覧はタイトル・説明・キーワード検索、3軸の絞り込み、件数・解除・0件案内・ページ送りを備え、条件をURLで共有・復元できる。JSなしでも全教材とテーマのリンクを利用できる。
目的別ルートは既存教材を参照する。本文は一つ。記事の次はシリーズの順序、ルートから来た場合はそのルートの順序に従う。前提、所属、目次、関連少数、戻り先を表示。
公開・内容更新・情報確認を別々に管理し、根拠のある日付だけを使用。新着・更新には読者向け要約。過去事例は対象時点と最新確認先を示す。
既存learn URLとトップのpaths/library/latestアンカーを維持。FIELD NOTES、猫A/C、最小文字・操作領域、README/LICENSE、教材の安全上の留保を保つ。ログイン・ダウンロード・作者向け説明を公開ページへ追加しない。
成功条件: 全ページ全契約幅のデザイン検査、型・ビルド・リンク・分類参照検査、検索/URL復元/回遊/文字200%/キーボード/JSなしを検証。効果の速度や成功率は利用者テスト前に断定しない。
