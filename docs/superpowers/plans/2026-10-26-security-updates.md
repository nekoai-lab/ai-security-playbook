# Security updates and automatic publishing
Goal: 承認された更新情報のUIを公開し、日報から一次確認・独立QA・CI・公開URL確認・事後通知までを定期実行する。
Architecture: 公開記事はデータのみのJSON。共通Astroテンプレートが描画し日報や任意コードを実行しない。非公開日報はminiで読み、Codexのこのスレッドの定期実行が処理。重複・処理状態は非公開のローカル台帳に保持し、公開本文へ流さない。
Constraints: 本体の作業中checkout/.envに触れない。一次資料不明・内部情報混入・レビュー/検査失敗は公開停止。ユーザーの事前確認待ちは不要。通知はこのチャットへ公開URL・変更点・未確認をまとめる。
Tasks:
- 更新データ契約/共通詳細/一覧とトップへの回遊・SEO/sitemap・テストを実装。
- 一次資料で今回のPython更新を再確認し、承認プレビューから最初の公開データを作る。
- 日報取得と処理台帳、再実行時の重複防止、別AIQAの公開手順を整備。
- 必須テスト/公開FULL/見本FULL/全幅ブラウザ検査/別AIQA/CIを通し公開、URL確認。
- このスレッドの定期チェックを登録。実際の未処理日報がない場合は取得状態を報告し、将来実行を実績と扱わない。
