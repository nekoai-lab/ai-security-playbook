# Node教材の学習導線を整える計画

Goal: Node.js教材を、理解・確認・記録まで進められる完成見本にする。
Architecture: 既存MDXとFlowを使って読み順を整理し、LessonRecordだけを再利用可能な独立部品として追加する。記録はブラウザ内だけで処理する。
Tech Stack: Astro / MDX / TypeScript / ブラウザ標準API。

- [ ] 仕様とL01–L05を追跡表へ追加し、変更前の代表画面を保存する。
- [ ] Node教材へ学習目標、実践へのリンク、確認・記録の流れを加える。公式発表の再確認日を反映する。
- [ ] LessonRecordと共通スタイルを実装する。空入力は案内、未確認のみは許可。保存・送信・安全性の自動判定はしない。
- [ ] ブラウザでダウンロード内容、入力の扱い、キーボード、JSなし、開いた記録欄の画面幅と文字拡大を確認する。
- [ ] 全体の型・ビルド・リンク・デザインハーネスを実行し、目視と残課題を記録する。
- [ ] PRとCIを確認し、承認済みの公開フローで反映して公開URLを確かめる。
