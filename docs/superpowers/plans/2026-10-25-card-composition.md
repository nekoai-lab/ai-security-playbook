# カードの密度と構図を整える Implementation Plan

**Goal:** 最終承認された場面画・のぞく・歩く・下部の挿絵を混ぜる構成を本番部品へ反映し、猫の反復を抑える。
**Architecture:** CardArtと明示的な用途別割り当てを共通化。本文のLessonSceneとOGPの素材指定は変えない。
**Tech Stack:** Astro / TypeScript / 既存WebP / CSS。

## Global Constraints
- 既存承認済みのポーズと場面の部分表示のみ。左右反転・生成・顔の切断をしない。
- 紙/黒/朱色の既存トークン、本文16px、注記12px以上、操作44px以上。
- 8テーマと24教材、検索条件・件数・直接記事遷移・ページング・JSなしのリンクを維持。
- サイト内カードにTsukineko署名を反復しない。本文、README、LICENSE、OGPを変更しない。
