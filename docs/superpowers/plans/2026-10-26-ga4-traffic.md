# GA4 traffic implementation plan

Goal: 本番の流入元・ページ閲覧・検索語をGA4ストリームG-Q83DQP6PS5へ送る。
Architecture: 共通ShellのheadにGoogleAnalyticsを一度だけ配置。本番build/runtime origin/baseガード後に標準gtag.jsをasyncで読み込む。設定は一度だけ、ページビュー/サイト内検索は既存の拡張計測に任せる。
Tech stack: Astro、Google tag、既存のqクエリと静的サイト。

- [x] ID・本番ガード・広告シグナル無効化を共通部品へ。Googleタグ標準のオプトアウトflagを尊重。手動page_view/view_search_resultsは追加しない。実測で標準が取得できない画面内検索は確定時だけsearchで補完し、検索語以外の入力は取得しない。
- [x] privacyページにCookie/URL/参照元/検索語/端末等の取得と目的、Googleの方針と拒否方法を表示。共通フッター/紹介ページから案内。新ページをreview-mapへ。
- [x] 本番/localhost/別origin/制作見本/opt-outのタグ挙動、初期化一度、実際の検索クエリ、通信失敗でも表示を妨げないことを検査。check/build/test、制作見本、公開/見本FULL・全画面4幅・文字200%・キーボード確認。
- [ ] PR・別AIレビュー・CI後に公開。実タグとcollect通信を確認。GAレポートの受信確認はサイト側の通信検証と区別する。
